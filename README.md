
# Shooter Game

A simple 2D space shooter developed in Python using Pygame and adapted to run in a web browser with Pygbag.

## Features

- Player-controlled spaceship
- Alien targets with increasing speed
- Projectile shooting and collision detection
- Score tracking
- Browser support using WebAssembly

## Controls

- Left Arrow — Move left
- Right Arrow — Move right
- Space — Shoot

## Technologies

- Python
- Pygame
- Pygbag
- WebAssembly

## Run Locally

Install the dependencies:

```bash
pip install pygame pygbag
```

Run the desktop version:

```bash
python main.py
```

Run the browser version:

```bash
python -m pygbag .
```
